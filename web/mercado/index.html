De dónde salen los datos

El valor de cada jugador es el que publica LaLiga Fantasy cada noche, hacia las 00:15, para todas las ligas. Aquí se compara con el del día anterior y con el de hace siete cambios, entre los 596 jugadores que siguen en LaLiga. Una racha cuenta los días seguidos que el valor sube (o baja) hasta hoy. Las cifras de cuánto duran las rachas salen de 52.302 cambios de valor de esta temporada (la guía de valor de mercado).
